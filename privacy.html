سياسة الخصوصية — جاهز Store

تاريخ آخر تحديث: 27 نوفمبر 2026

تلتزم منصة جاهز Store باحترام خصوصية مستخدميها وحماية البيانات التي يشاركونها عند استخدام التطبيق أو الموقع الإلكتروني لتصفح المنتجات والخدمات وطلب التوصيل أو التقديم كمناديب توصيل.

1. البيانات التي نقوم بجمعها

  • بيانات الطلبات والعملاء: الاسم الكامل، رقم الهاتف/الواتساب، منطقة التوصيل، العنوان التفصيلي (الشارع، رقم العقار، الدور، الشقة)، تفاصيل الطلبات العادية أو الطلبات الخاصة، وطريقة الدفع المختارة.
  • بيانات التقديم ككابتن توصيل: الاسم الكامل، رقم الهاتف/الواتساب، المنطقة/العنوان، وبيانات المحافظ الإلكترونية المقدمة طوعاً (مثل رقم فودافون كاش أو حساب إنستا باي) لتنظيم العمل والتسويات المالية.
  • البيانات التقنية والتخزين المحلي: قد يتم حفظ بعض بيانات الجلسة أو السلة أو البيانات المؤقتة لتحسين سرعة التحميل واستقرار عرض المنتجات والطلبات.

2. كيفية استخدام البيانات

  • تجهيز الطلبات وتوصيلها إلى العنوان المحدد وتنسيق التواصل بشأنها عبر الواتساب أو الهاتف.
  • الرد على الطلبات الخاصة ("اطلب اللي تحتاجه") وتقديم الدعم للمستخدمين.
  • مراجعة طلبات الانضمام كمناديب توصيل وتنظيم عمليات التسليم والتسويات.
  • تحسين أداء المتجر وتحديث المنتجات والعروض وتجربة الاستخدام.

3. مشاركة البيانات والإرسال عبر الواتساب

  • عند إرسال طلب أو طلب خاص أو طلب انضمام ككابتن، يتم توجيه تفاصيل الطلب إلى الجهة المختصة بالتشغيل والتوصيل (بما في ذلك فتح محادثة واتساب تحتوي على بيانات الطلب والعنوان لإتمام الخدمة).
  • لا نقوم ببيع بيانات المستخدمين الشخصية لأطراف ثالثة لأغراض دعائية خارجية.
  • قد يتم حفظ أو مزامنة بيانات التشغيل والطلبات عبر خدمات سحابية مرتبطة بالمنصة لتشغيل الخدمة ومتابعة الطلبات.

4. أمن البيانات والاحتفاظ بها

  • يتم نقل البيانات عبر اتصال مشفر (HTTPS) قدر الإمكان عند التواصل مع الخدمات الشبكية.
  • نحتفظ ببيانات الطلبات والسجلات التشغيلية للمدة اللازمة لإتمام الخدمة، ومتابعة الطلبات، والالتزام بالمتطلبات التشغيلية أو النظامية.

5. حقوق المستخدم والتواصل معنا

يحق للمستخدم طلب تحديث بياناته أو الاستفسار عن كيفية استخدامها أو طلب حذف بيانات التواصل المرتبطة به عبر قنوات التواصل الرسمية الخاصة بـ جاهز Store.
